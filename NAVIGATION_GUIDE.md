# Navigation Guide - BS Computer Science Page

## How to Access the BS Computer Science Page

### Option 1: Direct URL
Navigate directly to: `/admissions/undergraduate/bs-computer-science`

### Option 2: Header Menu Navigation
1. Click on **"Admissions"** in the header menu
2. In the dropdown, you'll see:
   - Undergraduate Programs
   - → BS Computer Science ← (Click here)
   - → BS Software Engineering
   - → BS Artificial Intelligence
   - → BS Data Science
   - Graduate Programs
   - (and other admission-related links)

### Option 3: From Undergraduate Programs Page
1. Go to `/admissions/undergraduate`
2. Click on the BS Computer Science program card/link
